01 · Entrada

Fuentes de imagen

0 fuentes
Falta la API key de Google Drive. El panel puede editar la demo, pero no leer carpetas nuevas. Abre assets/js/config.js, pega tu key en drive.apiKey y recarga esta página.
  1. Entra a console.cloud.google.com y crea un proyecto.
  2. Activa Google Drive API en «APIs y servicios».
  3. Crea una API key y restríngela a Google Drive API.
  4. Añade la restricción por dominio cuando publiques el panel.

Pega uno o varios enlaces. Se leen únicamente las carpetas públicas que aparezcan en este campo: el panel no recorre tu Drive ni pide acceso a tu cuenta.

Acepta enlaces de carpeta de Drive, archivos de Drive y URLs directas a imágenes. Google Fotos e iCloud no permiten lectura pública desde el navegador.

Empezar de cero

Vacía el borrador de este navegador. No borra el galeria.json que ya esté publicado en el sitio.

Publicar en GitHub Pages o Vercel: coloca el archivo en assets/data/galeria.json, haz commit y sube el repositorio. La galería se actualiza al recargar, sin API key y sin backend.
  1. Descarga galeria.json con el botón de arriba.
  2. Reemplaza assets/data/galeria.json en el proyecto.
  3. Revisa la portada, el archivo y el visor en local.
  4. Haz commit y publica con GitHub Pages, Vercel o Netlify.

04 · Referencia

Cómo funciona

Sin backend
Sobre la API key. Una API key en JavaScript es visible para cualquiera que abra el panel. Restríngela a Google Drive API y a los dominios donde lo publiques; si el panel es solo para ti, úsalo en local y no lo despliegues con la key.
  1. Comparte la carpeta de Drive como «Cualquiera con el enlace» y copia su URL.
  2. Pega uno o varios enlaces en Fuentes y pulsa «Escanear enlaces».
  3. Importa las imágenes y edita la ficha de cada obra: título, fecha, técnica, medidas, categoría y descripción.
  4. Usa las flechas de cada ficha para ordenar la curaduría. Ese orden es el que verá el público.
  5. Descarga galeria.json y colócalo en assets/data/. La galería lo lee al instante.

Sin galeria.json, el sitio muestra automáticamente las 32 obras de demostración. Un manifiesto publicado con cero obras muestra el estado vacío, no la demo.
